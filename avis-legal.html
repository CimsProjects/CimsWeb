Per a què serveix aquesta web

Aquesta web presenta CIMS, el Pol i el Martí, i els serveis de consultoria i de formació en intel·ligència artificial que oferim a empreses petites.

La informació és orientativa. Els preus i els terminis només són vinculants quan us els donem per escrit en un pressupost.

Propietat intel·lectual

Els textos, el logo i el disseny d'aquesta web són de CIMS. No els podeu reproduir ni fer-ne servir sense el nostre permís.

Privacitat

Aquesta web no té formularis i no recull cap dada personal vostra. No fem servir galetes (cookies) ni cap eina d'analítica o de publicitat.

  • Preferència de tema. Si trieu el tema clar o el fosc, el navegador ho desa al vostre dispositiu. No ens arriba a nosaltres i ho podeu esborrar quan vulgueu des del navegador.
  • Lletres de Google Fonts. Per mostrar les lletres, el navegador es connecta als servidors de Google, que reben la vostra adreça IP.
  • Allotjament a GitHub Pages. La web està allotjada a GitHub, que pot registrar l'adreça IP de les visites per motius de seguretat.

Si en algun moment ens doneu dades personals, per exemple per correu, les farem servir només per respondre-us. Podeu demanar accedir-hi, rectificar-les o esborrar-les escrivint-nos a l'adreça de més amunt. Si creieu que no les hem tractat bé, podeu reclamar a l'Agència Espanyola de Protecció de Dades.
